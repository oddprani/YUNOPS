# 🛸 YUNOPS

**YUNOPS** is a high-performance, real-time infrastructure monitoring dashboard designed for DevOps engineers. It provides a "single pane of glass" view into server clusters, container health, and network throughput.

## ✨ Key Features

-   **Live Telemetry**: Real-time CPU, Memory, and Network throughput (1s refresh rate).
-   **Security Suite**: Integrated vulnerability scanning and risk assessment.
-   **Infrastructure Overview**: Monitor pipelines, deployments, and distributed logs.
-   **Cross-Platform**: Adapts to Linux, macOS, and Windows environments using `systeminformation`.
-   **Glassmorphism UI**: A technical, dark-themed interface built with Tailwind CSS and Framer Motion.

## 🚀 Quick Start (Local Windows)

1.  **Clone / Download** the repository.
2.  Install [Node.js](https://nodejs.org/).
3.  Double-click **`start-windows.bat`**.
4.  Open [http://localhost:3000](http://localhost:3000).

## 🛠️ Tech Stack

-   **Frontend**: React, TypeScript, Tailwind CSS, Recharts, Lucide Icons.
-   **Backend**: Node.js, Express, `systeminformation` (Hardware abstraction).
-   **Motion**: Framer Motion for layout transitions.

## 🛡️ Security

YUNOPS includes a real-time vulnerability scanner that monitors:
-   SSL Certificate validity.
-   Open ports and bastion host security.
-   Database injection risks.
